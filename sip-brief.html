SIP Innovation Brief — FlagAI

FlagAI: A Referee Game-Day Assistant. Part 1 complete (SIP311); Parts 2 and 3 are written in SIP408 and SIP409.

Open the PDF

Technical field

Artificial Intelligence (rule-based expert systems and knowledge representation), Web Application Development, and Sports Technology, focused on decision support for football officiating.

Background

Officials must identify a foul, determine its enforcement, and manage the clock within seconds while applying a rulebook of 19 rules, each divided into sections and articles. Amateur crews often work without replay or a rules expert on site. The idea grew out of my coursework research on AI in professional football officiating and 13 years as a Navy Electrician's Mate, where standardized technical manuals guide time-critical decisions: officiating benefits from a fast, authoritative reference that returns a traceable answer rather than an opinion. Peer and SME review then refocused the concept from a penalty-call assistant into a referee-facing game-day app, because rule lookups alone are already available through general-purpose AI tools.

Innovation claim

This project is innovative because it unites a deterministic, citation-producing football penalty rule engine with roster and game-clock management in a single referee-facing application, so every ruling is repeatable, traceable to a specific rule, section, and article, and immediately reflected in the game state. Unlike general-purpose AI chatbots or static digital rulebooks, FlagAI returns the same verifiable answer for the same play every time.

Project description

A web-based game-day assistant for football officials, built in Python with Flask, combining three functions in one console: a deterministic rule engine (plain-text play in → foul, responsible player, enforcement, and rule-section-article citation out, written as original code rather than reproduced rulebook text); a roster module that attributes each foul to a player number and records it in a foul log; and a game-timing module for the game clock, play clock, quarters, and timeouts. The MVP uses professional football playing rules, and the engine is modular so other rule sets, such as high school rules, can be added.

Usage scenario

At a preseason clinic, an officiating association loads written play descriptions drawn from game film. Trainees record their rulings, and each is compared with the engine's determination and citation. Because the engine is deterministic, every trainee is measured against the same standard, and instructors can see which rule areas — pass interference, enforcement spots — produce the most errors. Crews use the same workflow after games to confirm disputed enforcements for evaluator reports. Rules coordinators, coaches, and broadcast analysts can test rule changes and verify explanations.
